# QA & Testing Support Dashboard

An interactive dashboard for tracking test results, bugs, code coverage, and CI/CD pipeline status — built around a real-world Python + AWS engineering stack.

**Live demo:**  https://harbirsinghsandhu.github.io/qa-testing-dashboard/

## Overview

This project simulates a QA & testing support workflow for a backend/data engineering team. It covers the kind of testing and quality processes used when working with cloud infrastructure (AWS), data pipelines (Pandas), APIs (FastAPI), and machine learning models (Scikit-learn).

## Features

- **Test suite tracker** — pass/fail/skip status across modules (boto3, Pandas, FastAPI, Scikit-learn), filterable by status
- **Bug tracker** — open issues with severity levels (critical, high, medium) and assignment
- **Code coverage by module** — visual breakdown of test coverage across the codebase
- **CI/CD pipeline history** — recent Jenkins and AWS CodePipeline run statuses
- **Daily test trend chart** — passed vs. failed tests over the last 7 days

## Tech stack

- HTML / CSS / vanilla JavaScript (no frameworks, no build step)
- Designed to reflect tooling from real Python/AWS development: `boto3`, `pandas`, `scikit-learn`, `FastAPI`, `PostgreSQL`, Jenkins, AWS CodePipeline, CloudWatch

## Why this project

As a Python developer with experience in cloud automation, data pipelines, and ML, I wanted a project that demonstrates QA thinking applied specifically to backend and data systems — not just traditional UI testing. This dashboard reflects the kind of test/bug/coverage visibility a QA or DevOps-minded engineer would want when supporting a Python/AWS-based product.
